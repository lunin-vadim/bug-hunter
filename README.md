# Bug Hunter

Полноэкранная браузерная аркада: устраняйте баги, пока они не добрались до продакшена. Регистрация, вход и рейтинг игроков по числу устранённых багов (PostgreSQL).

## Быстрый старт

Требования: Node.js 18+, PostgreSQL 16 (локально через скрипт или Docker).

```bash
npm install
npm run db:start      # локальный PostgreSQL на :5433 (данные в ./.pgdata); либо docker compose up -d
cp .env.example .env  # задайте JWT_SECRET: openssl rand -hex 32
npm start             # http://localhost:3131
npm run dev           # то же с автоперезапуском сервера (nodemon)
```

`npm run dev` перезапускает сервер при изменении `server.js`, `schema.sql` и `.env`; файлы из `public/` отдаются как статика, перезапуск для них не нужен.

Остановить БД: `npm run db:stop`. Схема применяется автоматически при старте сервера (`schema.sql`).

## Игровые механики

| Объект | Эффект |
| ------ | ------ |
| 🐛 🐞 🪲 | Обычные баги; у 🪲 два «хп» |
| 🪳 | При устранении делится на мелких |
| 🐝 | Золотой: бонус и пауза появления новых багов |
| 🐌 | Приманка: клик снимает очки и обнуляет комбо |
| 🧹 | Рефакторинг: появляется редко (с 4-й волны, не чаще раза в 30 с); устраняет багов в нижней половине поля, замораживает спавн и возвращает сердце |
| 🧊 | Code freeze: баги замедляются на 4 секунды |
| 💣 | Hotfix: взрыв устраняет багов в радиусе вокруг |
| 🎯 🧮 | Перки: начиная с 3-й волны, каждые 2 волны игра встаёт на паузу и предлагает выбрать 1 из 3 улучшений (клавиши 1–3 или нажатие): Снайпер (радиус клика), Тест-покрытие (сразу выпускает автотест и усиливает следующие), Золотая жила, Охлаждение (баги медленнее), Азарт+ (множитель раньше), Сапёрка (Hotfix), Бонусные очки (+15% очков за уровень), а также разовые Бэкап (+сердце) и Файрвол (щит). Два перка «с подвохом» (оранжевая карточка): Технический долг (+40% очков, но баги на 15% быстрее) и разовый Откат (убирает всех багов на поле ценой сердца; предлагается, только если сердец больше одного). При выборе «Тест-покрытия», «Золотой жилы» и «Сапёрки» на поле сразу появляется соответствующий бонус (робот, золотой жук, бомба), а «Охлаждение» сразу замораживает баги на 4 с, чтобы эффект был виден в момент выбора. После выбора карточка подсвечивается, приходит тост с описанием, а значок перка «выпрыгивает» в полоске слева. Уровни складываются до 2–3; собранное видно значками слева над прод-линией. Если идёт бой с боссом, выбор откладывается до его конца |
| 🤖 | Автотест (с 3-й волны) — **редкий и ценный** бонус: не чаще раза в 60 секунд и не больше одного на поле (перк «Тест-покрытие» сокращает паузу на 20% за уровень), с пульсирующим кольцом и сигналом при появлении. 6 секунд бот (выстрел раз в 0,7 с) сам бьёт самых близких к проду багов (по боссу вполсилы), сам не трогает золотых, приманки и бонусы; комбо и «Азарт» не затрагивает. Повторный подбор продлевает до 9 секунд. Ачивки: «Первый автотест», «QA-инженер» (5 штук), «Автоматизатор» (50 багов руками бота), «Тесты прошли» (добить босса автотестом) |
| 👾 | Босс: приходит на 5-й волне и дальше каждые 4 волны (9, 13, …), независимо от набранных очков. Закликайте его, пока не дополз до прода (победа: +150 очков и сердце; прорыв: −2 сердца). Три фазы по здоровью (пороги отмечены на полосе): обычная; «Хаос» с 60% — раз в 2,6 с телепортируется, а за 0,65 с до прыжка мигает и показывает пунктирным кольцом, куда прыгнет; «Ярость» с 25% — залп из трёх миньонов, спускается в 1,6 раза быстрее и зовёт миньонов почти вдвое чаще. Перк, выпавший на волну босса, предлагается после боя. Боссы чередуются: 👾 баг-босс, 🗿 «Легаси-монолит» (4 вращающихся блока 🧱 по 3 хп; пока цел хоть один, по телу урона нет; бомбы, рефакторинг и автотест бьют сначала по блокам; в каждой новой фазе один разбитый блок возвращается) и ⏰ «Дедлайн» (не спускается, но тикает таймер 26 с, у каждого следующего на 2 с меньше, минимум 16; в «Ярости» таймер идёт в 1,5 раза быстрее, code freeze его замедляет; не успели — как прорыв, −2 сердца). У монолита и дедлайна 80% здоровья классического. Hotfix и Рефакторинг бьют по нему тоже. Ачивки: «Завалил босса», «Охотник на боссов» (5 за всё время, даёт титул), «Дубль» (двух за партию), «Без единой царапины» (победа без потери сердец за бой), «Тесты прошли» (добить автотестом) |
| 🎵 | **Звук и музыка управляются раздельно.** Кнопка с динамиком (`M`) отвечает только за звуковые эффекты, кнопка с нотой (`N`) — за фоновую музыку. Громкость каждой настраивается ползунком в блоке «Громкость» на стартовом экране и экране паузы (по отпусканию звучит пробный сигнал или фрагмент мелодии; если поднять ползунок при выключенном звуке или музыке, они включаются). Все настройки запоминаются; тем, кто раньше выключал «звук» целиком, музыка остаётся выключенной, пока они сами её не включат |
| 📳 | **Вибрация** на телефоне (кнопка с вибрирующим телефоном в панели значков, видна только на сенсорных устройствах; по умолчанию включена, кроме режима «меньше движения»). У каждого звука свой тактильный отклик: короткий тик за каждого убитого (сильнее при серии 10+), долгий за потерю сердца, ритм при победе над боссом и повышении ранга. Работает на Android через `navigator.vibrate`. На iPhone Safari этот API не поддерживает, поэтому там используется обходной путь через системный переключатель (`<input switch>`): он срабатывает только на касаниях (попадания, бонусы, выбор перка), а события вне касания (потеря сердца, прорыв босса) без вибрации |
| 📅 | **Задача дня.** Карточка на стартовом экране: у всех игроков в течение суток (по UTC) одна и та же последовательность жуков, событий и перков и один мутатор дня (Спринт: баги быстрее на 20%, Хрупкий прод: 3 сердца, Шторм: события подряд, Золотой день: золотых втрое больше, Горячая серия: «Азарт» на 4 попадания раньше). Играть можно сколько угодно раз, в таблицу идёт лучшая попытка дня. Вкладка «Сегодня» в рейтинге показывает топ-20 и ваше место. Одинаковая последовательность строится из общего сида (дата → хеш → mulberry32, три независимых потока: жуки, события, перки), поэтому клики игрока не сбивают её. Результат засчитывается в задачу дня, только если клиент прислал сегодняшнюю дату по UTC сервера. **Призрак дня:** ход лучшей сегодняшней попытки (счёт по секундам) хранится в браузере, и во время следующих попыток под HUD видно, насколько вы опережаете его или отстаёте на той же секунде |
| 🗓️ | **Челлендж недели.** Вторая карточка на стартовом экране (фиолетовая): всю ISO-неделю (с понедельника по UTC) у всех одна последовательность и сразу **два** мутатора из списка задачи дня. Сид недели свой (`week:2026-W46`), поэтому не совпадает ни с одним днём. Лучшая попытка недели идёт во вкладку «Неделя» рейтинга; призрак тоже работает. Сервер засчитывает результат в неделю, только если клиент прислал текущую неделю (`isoWeek` в `daily.js`) |
| 🔥 | «Азарт»: каждые 10 попаданий подряд — множитель очков (×2 с 10-й серии, ×3 с 20-й). Промах мимо жука, приманка или пропущенный баг обнуляют серию и множитель |
| 🌧️ 🐝 🧱 | Случайные события (со 2-й волны, раз в 18–30 с): Дождь багов (7 с густого потока лёгких жуков), Золотая лихорадка (8 с золотых, но каждый пропущенный стоит жизни), Стена багов (строй жуков по всей ширине), Пятничный деплой (с 4-й волны: на 10 с прод-линия плавно поднимается на 13% высоты), Код-ревью (8 с промахи мимо жуков не сбрасывают серию) |
| 🦟 🕷️ 🦂 | Новые жуки по волнам: комар (с 4-й, летит зигзагом), паук (с 6-й, делает рывок), скорпион (с 8-й, 4 хп). Остальные виды тоже открываются постепенно: к 4-й волне набор полный |
| 🦗 🐜 🦠 🪰 👻 | Поздние волны: flaky-сверчок (с 5-й, время от времени прыгает вбок), регрессия (с 7-й, после смерти один раз возвращается выше), утечка памяти (с 9-й, раз в 1,8 с растёт: +1 хп, крупнее и медленнее, до 4 хп), race condition (с 10-й, пара связанных мух: второго надо убить за 1,2 с после первого, иначе первый воскреснет; успел — +6), гейзенбаг (с 12-й, становится почти невидимым у курсора) |
| ⭐ | Элита: с 10-й волны часть обычных жуков приходит элитными (оранжевое свечение, +1 хп, очки ×2); доля растёт с 15% до 35% |
| 💡 | Подсказки: при первой встрече с жуком, бонусом или боссом всплывает карточка с тем, что он делает. Показывается один раз (запоминается в браузере) |
| 🛡️ 🔧 | Укрепления прода: падают, пока идёт бой с боссом. Щит гасит 4 прорыва (на линии горит голубая полоса), патч чинит полсердца (при полных сердцах даёт +1 заряд щита) |

**Итоги партии.** После поражения под счётом показываются график очков по волнам, кто последним прорвался и на какой волне, и лучшие моменты (серия, боссы, лучший взрыв, лучшая волна). Кнопка «Поделиться результатом» собирает картинку 1200×630: на телефоне открывается системное меню «Поделиться», на компьютере картинка скачивается, а текст результата копируется в буфер.

Бонусы 🧊 и 💣, дойдя до красной линии, исчезают без штрафа. После паузы идёт обратный отсчёт 3-2-1. Серия попаданий даёт бонусные очки, а за вехи комбо показываются баннеры. Тряску и вспышки можно отключить (`V`); по умолчанию они выключены, если в системе включено `prefers-reduced-motion`.

## Установка и офлайн

Игра — PWA: `public/manifest.webmanifest` (иконки в `public/icons/`) и `public/sw.js`. Её можно установить на телефон или компьютер («Добавить на главный экран» / «Установить приложение»), она открывается во весь экран. Service worker работает по принципу «сначала сеть»: пока сервер доступен, приходят свежие файлы, а без сети оболочка игры берётся из кэша и запускается в гостевом режиме (рейтинг, кабинет и челленджи без сети недоступны). Запросы `/api/*` и `/healthz` не кэшируются. При изменении списка файлов оболочки поднимите версию `CACHE` в `sw.js`.

## Личный кабинет, рейтинг, титулы и ачивки

- **Кабинет** (`C` или кнопка с силуэтом): аватар и цвет, статус и «о себе», выбор титула, история последних 20 партий, смена имени (раз в 7 дней) и пароля, сброс статистики, удаление аккаунта. Опасные действия подтверждаются паролем.
- **Рейтинг** (`L` или вкладка на правом краю): выезжающая панель с тремя сортировками: «За всё время», «За раз» (максимум багов за одну партию) и «Очки». Открытие во время партии ставит её на паузу.
- **Ранги** по числу устранённых багов: Стажёр → Джуниор (100) → Мидл (500) → Сеньор (2000) → Тимлид (5000) → Архитектор (15000). Плюс титулы за отдельные ачивки.
  - У каждого ранга свой значок и цвет: он виден в рейтинге, у игрока на стартовом экране и в кабинете. С ранга Сеньор вокруг аватара появляется сияние, у Тимлида и Архитектора оно сильнее.
  - В кабинете карточка ранга: прогресс считается внутри текущего ранга, ниже лестница из шести ступеней; по нажатию на ступень видно, что она открывает.
  - **Награды за ранги.** Аватары и цвета профиля открываются по мере роста: новичку доступен базовый набор (6 аватаров, 4 цвета), остальное закрыто замком. Свой цвет через палитру открывается с ранга Сеньор. Награды проверяются на сервере (`achievements.js`: `RANK_UNLOCKS`), а то, что игрок выбрал раньше, остаётся за ним.
  - При повышении ранга после партии показывается праздничная карточка с новым значком и списком открытых наград.
- **Ачивки** (18 штук, каталог в `achievements.js`) считаются на сервере при сохранении партии и привязаны к аккаунту.

> Расширенная статистика партии (комбо, волна, бонусы) приходит от клиента, и сервер проверяет только границы правдоподобия (комбо не больше убитых, волна не выше возможной за время партии и т. п.). Это защищает от случайных ошибок и грубой накрутки, но не от целенаправленной подделки запросов.

Смена пароля увеличивает `token_version`: сессии на остальных устройствах перестают действовать.

## Деплой: Render Free + Prisma Postgres

`render.yaml` — Blueprint бесплатного веб-сервиса. База внешняя — Prisma Postgres: в панели Render задайте `DATABASE_URL` = строка **пула** (`postgres://USER:PASSWORD@pooled.db.prisma.io:5432/postgres?sslmode=verify-full`). `JWT_SECRET` Render генерирует один раз. Сборка — `npm ci --omit=dev`, Node 22 (`engines`). Сжатие и HTTPS делает балансировщик Render.

**Ограничения бесплатных тарифов и что сделано под них:**

| Лимит | Что делает сервер |
| --- | --- |
| Prisma Free: **200 000 операций в месяц** (каждый SQL-запрос — операция; при исчерпании база недоступна до конца месяца) | Проверка здоровья Render — `/livez` без БД (`/healthz` с БД — только для ручной проверки). Строки пользователей кэшируются на 60 с (свои изменения обновляют кэш сразу), топ-20 рейтингов — на 30 с. Сохранение партии — 6–7 запросов. Схема применяется при старте, только если `schema.sql` изменился (хеш в `schema_meta`) |
| Prisma Free: 10 пул-соединений | `PG_POOL_MAX=5` |
| Prisma Free: нет автоматических бэкапов | `npm run db:backup` с `DIRECT_URL` (прямая строка, `db.prisma.io`) — `pg_dump` в `backups/` (в `.gitignore`); `pg_dump` должен быть не старше версии сервера |
| Render Free: засыпает после 15 мин без запросов, просыпается ~минуту; 750 инстанс-часов в месяц | Один сервис 24/7 — ~720 ч, укладывается. Чтобы не засыпал, можно пинговать `/livez` внешним мониторингом раз в 10–14 мин (запросов к БД это не тратит) |

**Автобэкап.** `.github/workflows/db-backup.yml` каждый день в 02:17 UTC (и вручную: Actions → DB backup → Run workflow) снимает `pg_dump` 17, шифрует его AES-256 (`openssl enc -pbkdf2`) и загружает артефактом на 30 дней; перед загрузкой проверяет, что файл расшифровывается и в нём есть таблицы с данными. Шифрование обязательно: репозиторий публичный, артефакты может скачать любой пользователь GitHub. Секреты репозитория (Settings → Secrets and variables → Actions): `DIRECT_URL` — **прямая** строка Prisma (`db.prisma.io`), `BACKUP_PASSPHRASE` — длинный случайный пароль (`openssl rand -base64 32`); сохраните его в менеджере паролей, без него бэкапы не расшифровать. Скачать и расшифровать свежий бэкап: `BACKUP_PASSPHRASE='…' npm run db:fetch-backup` (файл ляжет в `backups/`), восстановить: `pg_restore --clean --if-exists --no-owner -d "$TARGET_URL" backups/<файл>.dump`. `pg_dump` тратит запросы из квоты Prisma (порядка сотни за бэкап). GitHub отключает расписание в публичном репозитории после 60 дней без коммитов — тогда включите его снова на вкладке Actions.

**Сколько это игр.** Примерно: вход на страницу залогиненного игрока — 1–3 запроса, гостя — почти 0 (кэш), сохранение партии — 6–7, плюс 1–2 при открытии рейтинга. Это порядка 10 запросов на партию, то есть ~20 000 сохранённых партий в месяц (~650 в день). Расход виден в Prisma Console или `npx prisma postgres usage`. Если упрётесь — Starter-план Prisma ($10/мес, 1 млн операций) снимает ограничение без изменений в коде.

## Архитектура

- `public/` — клиент: canvas-игра без сборки. Без сервера открывается в гостевом режиме; `sw.js` и `manifest.webmanifest` делают её устанавливаемой и доступной офлайн.
- `server.js` — Express-сервер: API, статика, проверка здоровья.
- `profile.js` — роутер личного кабинета; `achievements.js` — каталог ачивок и титулов (чистые функции).
- `schema.sql` — схема БД (`users`, `games`).

## Безопасность

- Пароли хранятся как bcrypt-хэши; сессия — JWT в httpOnly-cookie с `SameSite=Strict`.
- Эндпоинты входа и регистрации ограничены по частоте запросов.
- Результат партии валидируется на сервере: отсекаются нереалистичные значения и слишком частые отправки. Клиенту сервер не доверяет.
- Заданы заголовки безопасности: Content-Security-Policy, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`.
